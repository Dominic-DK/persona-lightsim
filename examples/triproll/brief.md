# TripRoll 제품 현실 브리프 (감사 완료 · 2026-08-25)

표기 규칙: 표시 없는 문장은 **레포 코드로 검증된 사실**. `[설계]`는 PRD/README의 의도이며 코드에 없음. `[추정]`은 근거 없는 가설.

## 한 줄 정의

여행 일행이 각자 찍은 사진을 한 롤에 모아, 여행이 끝나면 자동 편집된 짧은 영상으로 돌려주는 iOS 앱 + 웹 참가 페이지.

## 핵심 가설 (PRD)

공유앨범은 사진을 모으지만 작품을 만들지는 않는다. 가장 먼저 검증할 것은 **"여행영화라는 결과물에 돈을 내는가"** — 공유앨범 기능 자체는 경쟁 제품이 충분히 제공하므로 차별점이 아니다.

## 설계 플로우 (PRD) vs 코드

1. 호스트가 여행명·목적지·시작일·**총 컷 수**·촬영 스타일을 정해 롤을 만든다. — 구현됨. **`공개 시점` 입력은 생성 폼에 없다**(`rolls.reveal_at` 컬럼은 존재하나 코드 어디서도 읽거나 쓰지 않음).
2. 참가자는 링크 또는 롤 ID로 참여한다. `[설계]` QR은 코드에 전혀 없다.
3. 참가자별 촬영 제한과 미션을 따른다. — **둘 다 사실이 아니다.** 컷 제한은 참가자별이 아니라 **롤 전체가 나눠 쓰는 하나의 예산**이고(앱 UI 문구도 "총 컷 수"), 미션은 테이블도 필드도 없다. 스타일 4종을 "촬영 미션"이라 부르는 카피만 있다.
4. 여행 중 사진은 공개 시점까지 잠긴다. — **iOS 화면에서만 성립한다.** 웹 참가 페이지는 촬영 중에도 전원의 사진을 서명 URL 갤러리로 즉시 보여준다(같은 페이지 하단에 "사진은 롤이 현상될 때까지 잠겨 있어요"라는 반대 카피가 같이 떠 있다). DB 정책도 멤버 전원에게 상시 읽기를 허용한다. 시간 기반 잠금은 없고, 호스트가 "현상 시작"을 누르는 순간이 곧 공개다.
5. 현상 → 자동 러프컷 → 감독판 주문. — 러프컷·감독판 **렌더는 실제로 동작한다**(아래).

## 구현 현실 (코드 검증)

**영상 산출 경로가 셋 있고, 전부 실제로 MP4를 만든다. 목업이 아니다.**

- **서버 러프컷** (`scripts/roughcut_worker.py`): 현상 시 자동 큐잉 → A0 분석기로 선별 → ffmpeg concat → 비공개 버킷에 저장 → 앱 현상소에서 실제 재생. **1280×720 가로(16:9), 무음**, 사진 2초(훅 컷만 3초).
- **서버 감독판** (`scripts/director_cut_worker.py`): ReelForge/HyperFrames로 실제 렌더. 다만 **연출은 자리표시자**다(코드 주석이 "임시 배선 스캐폴드"라고 명시). 나레이션이 `"{여행명}. {목적지}의 사진 장면입니다"` 템플릿, 오디오는 무음 트랙, 모든 컷이 동일한 풀블리드 플레이트. 즉 **파이프라인은 진짜, 작품성은 아직 없다.**
- **아이폰 온디바이스 편집** (`TripRollDeviceRenderer.swift`): 앱 안에서 바로 렌더. **1080×1920 세로**, 켄번즈 줌·팬, 페이드, 타이틀 카드, 무음. 렌더 후 공유 시트로 바로 내보낼 수 있다. **세로 영상을 내는 유일한 경로가 이것이다.**

**A0 자산 분석기**(`scripts/asset_router.py`)는 실제로 돈다: EXIF 촬영시각·GPS 추출, 90분 갭 기준 챕터 분리, 300m 반경 위치 클러스터, pHash 중복 제거, 선명도·노출 기반 품질 점수, 최고점 컷을 맨 앞에 배치. 단 **내용 분류는 미구현**이라 `content_class`가 항상 "unknown", 얼굴 수가 항상 0이다. 그래서 "음식형·인물형" 포맷은 호스트가 스타일을 직접 고른 경우에만 도달하고, 자동 라우팅은 사실상 루트형/희소형/시간순 셋으로만 갈린다.

**웹 참가**: 롤 ID(UUID 36자)와 이름으로 익명 세션 생성 → 참여 → 사진 업로드 → 참가자 목록·모인 사진 확인. **사진만 받는다(영상은 거부).** 업로드 시 촬영시각으로 브라우저 파일 수정시각을 쓰고 **GPS는 아예 보내지 않는다** — 반면 iOS는 사진 라이브러리에서 정확한 촬영시각·GPS를 실어 보낸다.

**미구현**: QR 초대, 결제, 사용자 계정, 미션, 시간 기반 공개 예약, 포토진, 참가자별 엔딩 크레딧. "감독판 주문하기" 버튼은 "다음 단계에서 결제와 편집을 연결합니다"라는 안내 알림만 띄운다 — 그런데 **바로 옆 "감독판 만들기" 버튼은 무료로 실제 감독판을 큐에 넣는다.** 현재 제품에는 지불 게이트가 한 군데도 없다.

**인프라**: 로컬 Supabase + 같은 Wi-Fi. 앱과 웹 모두 **사설 IP가 하드코딩**되어 있어(`http://10.250.14.182:...`) 초대 링크가 같은 네트워크 밖에서는 열리지 않는다. 서버 워커 둘은 개발 머신 전용(서비스 키·ffmpeg·로컬 ReelForge 체크아웃 필요). 출시 인프라가 아니다.

## 과금 가설 (전부 `[추정]` — 결제 코드 0줄, 검증된 적 없음)

여행당 자동 러프컷 9,900원 / 큐레이션 감독판 49,000~149,000원 / 크리에이터 전용 롤 수익 배분 / 여행사·웨딩·워크숍 브랜디드 패키지. 이 숫자는 README의 초기 수익 가설일 뿐 실제 판매·설문·과금 실험이 없다.

## 경쟁 현실 (레포에 기록된 2차 리서치)

Retro(그룹 앨범·월간 리캡), disposable.photo(QR 참여·컷 제한·이벤트별 과금·지연 공개), Unposed(앱 설치 없는 QR·게스트별 24컷·이벤트별 과금), Lense(여행용 공유앨범·지연 공개, 10만+ 여행자 *표방*), CrowdRiff Creators(여행 브랜드용 크리에이터 콘텐츠). **디지털 일회용 카메라·지연 공개·컷 제한은 이미 흔하다.** 주목할 점: 경쟁사들은 **게스트별** 컷 제한과 QR 참여를 이미 제공하는데, TripRoll은 둘 다 없다. TripRoll의 쐐기 `[설계]`는 역할·미션 기반 촬영 → 스타일 있는 러프컷 → 감독판이라는 "여행영화 제작" 층이다.

## 성공 신호 (PRD)

한 롤에 5명 이상 참여, 참가자 70%+가 3컷 이상 업로드, 공개 순간 그룹 동시 재생, 결과물의 인스타 스토리·단체 채팅 공유, 다음 여행용 롤 재생성, 러프컷/감독판 실제 결제.

## 알려진 실전 약점

- **모든 산출물이 무음이다.** 세 경로 전부 오디오를 넣지 않는다. 음악 없는 "여행영화"는 스토리 공유 성공 신호와 정면으로 부딪힌다.
- **주력 산출물이 가로다.** 자동 러프컷은 16:9 720p인데 공유 목표는 세로 스토리·단톡이다. 세로 1080×1920은 아이폰 온디바이스 경로에서만 나온다.
- **감독판이 아직 감독하지 않는다.** 렌더는 되지만 연출이 템플릿 문구·균일 플레이트라, 49,000~149,000원의 근거가 될 품질 차이가 현재로선 없다.
- **웹 참가자가 2등 시민이다.** 사진만 가능, 영상 불가, GPS 없음, 촬영시각 부정확 → 그 사람들의 컷은 A0의 루트·챕터 판단에서 사실상 배제된다. 앱을 안 깐 친구일수록 결과물 기여도가 낮아진다.
- **지연 공개가 웹에서 깨진다.** 앱 사용자는 잠긴 화면을 보고, 웹 참가자는 실시간 갤러리를 본다. 같은 롤에서 두 사람의 경험이 다르다.
- **참가 마찰**: QR 없음, 36자 UUID 수동 입력 또는 링크 공유, 그 링크가 사설 IP라 실제 여행 상황에서 못 쓴다.
- **신원이 익명 세션 하나에 걸려 있다.** 계정이 없어 앱 재설치·세션 소실 시 호스트 자격과 롤 접근권을 복구할 방법이 없다. 앱에 호스트/참가자 구분 UI도 없어서, 참가자가 "여행 종료·현상 시작"을 누르면 서버는 거부하는데 그 사람 화면만 "현상 중"으로 바뀐다.
- **컷 제한이 공유 예산이라 선착순 경쟁이 된다.** 한 명이 48컷을 다 쓰면 나머지는 못 올린다. 게다가 클라이언트에서만 막고 DB 제약이 없다.
- **결제 이전에 무료 감독판이 열려 있다.** 지불 의사를 물을 자리에 무료 버튼이 있다.

## 분석가에게 주는 포지셔닝 질문

- "여행영화에 돈을 낸다"가 성립하는 세그먼트는 누구인가 (친구 여행/커플/가족/웨딩·이벤트/크리에이터)?
- 호스트 1인이 결제하는 구조인가, 참가자 분담인가 — 어느 쪽이 각 시장에서 자연스러운가?
- 러프컷 9,900원과 감독판 49,000~149,000원 사이의 가격 공백에 대한 반응은?
- 컷 제한·지연 공개가 "재미"로 읽히는 시장과 "불편"으로 읽히는 시장은 어디인가? 특히 **컷 제한이 참가자별이 아니라 롤 공유 예산**일 때 어떻게 읽히는가?
- 무음·가로 자동 편집본이라도 "받을 만한 결과물"로 인정되는 시장이 있는가, 아니면 음악·세로가 최소 요건인가?
