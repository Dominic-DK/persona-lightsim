# 국가 단위 페르소나 분석 방법론

readlate 10개국 분석(2026-08-21)에서 검증된 절차. 핵심은 **실카운트 → 정독 → 정형 출력**의 3단이며, 어느 단계도 건너뛰지 않는다.

## 1단: 정량 스크리닝

python3 표준 라이브러리(json, re, collections)만으로 스크리닝 스크립트를 작성한다. pandas 불필요 — 표본은 ~2MB JSONL이다.

**텍스트 필드**: `persona`, `professional_persona`, `arts_persona`, `hobbies_and_interests_list`, `skills_and_expertise_list`, `career_goals_and_ambitions` 를 합쳐 하나의 blob으로 매칭한다. 인구 통계는 `sex/age/education_level/occupation/province`.

**키워드 사전 설계 원칙**:
- 반드시 그 나라 언어의 관용 표현으로 직접 설계한다. 영어 키워드의 번역이 아니라, 그 문화에서 실제로 쓰는 말(한국 '자격증'·'인강', 일본 '資格取得'·'買い切り', 프랑스 'club de lecture'·'VO')을 쓴다.
- 세그먼트는 제품 브리프의 기능·과금과 연결되도록 잡는다 — "취미 분류"가 아니라 "이 제품을 쓸/안 쓸 이유" 기준.
- 카운트는 페르소나 단위(같은 사람의 중복 히트는 1)로 센다.

**오탐 검증은 의무다**: 히트 수가 작은 핵심 키워드는 히트 문맥을 전부 눈으로 확인한다. 기지 오탐 패턴 — 동음이의(원서=입사지원서), 동사 활용형(anime=animer 활용), 은유 관용구(translate vision into...), 지명(Promenade des Anglais). 제외한 오탐은 리포트에 "오탐 정직 보고"로 남긴다.

## 2단: 정성 정독

신호가 잡힌 페르소나를 세그먼트별로 뽑아 **30명 이상 원문 정독**한다. 목적: %가 말해주지 않는 것 — 계기, 사용 맥락, 지불 심리, 이탈 지점 — 을 실제 서사에서 찾는다. 시나리오에 쓸 인용문을 이 단계에서 수집한다(페르소나 원문 그대로, 직업·나이 병기).

## 3단: 7섹션 정형 리포트 (120줄 이내)

서론·맺음말·면책 문구 없이 아래 순서 그대로:

1. **표본 인구 스냅샷** — 연령·학력·직업 분포의 특징만 3~4문장
2. **타깃 세그먼트 정량화** — 표: 세그먼트 | % (n) | 대표 근거 키워드와 실카운트. 오탐 제외 내역 포함
3. **대표 유즈케이스 시나리오 5~7개** — 각각: 실인용(직업, 나이) + 계기 + 사용 흐름(제품 기능 단위) + 빈도 + 지불 여부 + 이탈 위험. 반례(안티 페르소나) 1개 포함 권장
4. **이 시장에서의 강점** 3~5개
5. **약점/블로커** 3~5개
6. **지불 의사 판독** — 과금 구조 대안 간 판정과 근거
7. **킬러 인사이트 1~2개** — 이 시장에서만 보이는, 행동을 바꾸는 발견

## 지켜야 할 것

- **숫자 날조 금지**: 모든 %는 1단 스크립트 출력에서만. 시장 지식 기반 추론(기기 보급률, 결제 문화)은 "추론"이라 표시.
- **브리프가 사실의 전부**: 제품 기능·가격·약점은 브리프에 적힌 것만 전제한다. 브리프에 없는 기능을 가정한 시나리오 금지.
- **합성 데이터 한계**: 페르소나는 인구 구성이지 행동 로그가 아니다. 결론은 "방향 가설"로 쓴다.
